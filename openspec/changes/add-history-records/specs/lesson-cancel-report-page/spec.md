## MODIFIED Requirements

### Requirement: 消课表页面整体布局
系统 SHALL 在消课表页面顶部显示页面标题"消课表"与操作工具栏（含"生成消课表"按钮、"导出 Excel"按钮、"历史记录"按钮），页面内依次包含：Excel 上传区域、（可选）月份选择弹窗、异常告警面板、消课矩阵区域。

#### Scenario: 初始空状态
- **WHEN** 用户首次进入消课表页面，尚未上传文件
- **THEN** 上传区域显示引导文字，矩阵区域与告警面板不显示

#### Scenario: 历史记录按钮可见
- **WHEN** 用户查看页面工具栏
- **THEN** 工具栏显示"历史记录"按钮，点击打开历史记录抽屉，抽屉仅展示 lesson-cancel 类型的记录

#### Scenario: 上传后未生成
- **WHEN** 用户上传文件解析成功但尚未点击"生成消课表"
- **THEN** 页面显示原始数据预览，矩阵区域不显示，提示用户点击"生成消课表"

### Requirement: "取值"sheet 上传与解析
系统 SHALL 支持拖拽/点击上传 `.xlsx`/`.xls` 文件，在前端使用 SheetJS 解析。系统 SHALL 优先解析名为"取值"的 sheet；若不存在则解析第一个 sheet。要求结构：第 0 行为表头（无标题行），列依次为 `日期/时段/科目/老师/次数/学员姓名/年级/班型/学生人数`。解析成功后 SHALL 将完整结果与原始文件二进制写入 IndexedDB 历史记录。

#### Scenario: 解析成功
- **WHEN** 用户上传结构合法的 Excel 文件
- **THEN** 系统解析出表头与数据行，显示原始数据预览表与成功提示；同时写入一条 lesson-cancel 历史记录

#### Scenario: 上传非 Excel 文件
- **WHEN** 用户上传非 `.xlsx`/`.xls` 文件
- **THEN** 系统拒绝并提示"仅支持 .xlsx / .xls 格式"，不写入历史记录

#### Scenario: 文件内容为空或格式不符
- **WHEN** Sheet 行数不足 2 行或数据区域为空
- **THEN** 系统提示"文件内容为空或格式不符，请使用模版填写后上传"，不进入矩阵流程，不写入历史记录

#### Scenario: 表头列缺失
- **WHEN** 第 0 行缺少 `日期`/`时段`/`次数`/`学员姓名`/`班型` 任一必需列名
- **THEN** 系统提示缺少哪些必需列名，不进入矩阵流程，不写入历史记录

#### Scenario: 重新上传替换数据
- **WHEN** 用户在已有数据的情况下再次上传新文件
- **THEN** 旧数据与矩阵清空，以新文件内容替换，新解析结果写入为新历史记录

#### Scenario: 从历史记录回填
- **WHEN** 用户在历史抽屉点击某条记录的"查看"
- **THEN** 系统将该记录 payload 的 `rawRows`/`validRows`/`invalidRows`/`matrix`/`targetMonth` set 回页面 state，关闭抽屉，页面展示当时的矩阵与告警
